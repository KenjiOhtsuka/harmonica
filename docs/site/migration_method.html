Migration method

A migration extends AbstractMigration and implements up() and down(). Inside those methods the whole DSL is available, and column builders inside createTable { }. The authoritative signatures are on the AbstractMigration API page.

Creating and dropping tables

  • createTable("users") { ... } — create a table; the block declares its columns and indexes.
  • dropTable("users") — drop a table.
  • renameTable("members", "users") — rename a table.

Column builders (inside createTable)

  • varchar("name", size = 100), string(...) — a text column of a given size.
  • integer(...), bigInteger(...), decimal(...) — numeric columns.
  • boolean(...) — a boolean column.
  • date(...), time(...), dateTime(...), timestamp(...) — temporal columns.
  • text(...) — a long text column.
  • blob(...) — a binary column.
  • refer("company") — a foreign key column (e.g. company_id) referencing the given table; also accepts nullable, default, and columnName.
  • comment("...") — a column comment.
  • Builders accept nullable and default (and size for varchar — MySQL defaults to 255 — plus unsigned for integer columns on MySQL).

Adding columns to an existing table

  • addVarcharColumn, addIntegerColumn, addBigIntegerColumn, addDecimalColumn, addBooleanColumn, addTextColumn, addBlobColumn — each takes the table and column name (and column settings).
  • addDateColumn, addDateTimeColumn, addTimeColumn, addTimestampColumn — temporal variants.
  • removeColumn("users", "address") — drop a column.
  • renameColumn("users", "name", "username") — rename a column.

Indexes and foreign keys

  • createIndex("users", "name") — create an index on one or more columns (unique and index-name variants exist).
  • dropIndex(tableName, indexName) — drop an index.
  • renameIndex(tableName, oldIndexName, newIndexName) — rename an index.
  • addForeignKey("users", "companyId", "companies", "id") — add a foreign key constraint.
  • dropForeignKey(tableName, columnName) — drop a foreign key.

Low-level SQL

executeSql("INSERT INTO ...") runs raw SQL against the connected database.

Supported database systems

The Dbms enum covers PostgreSQL, MySQL, SQLite, SQLServer (adapter registered, not yet implemented), Oracle, and H2.
