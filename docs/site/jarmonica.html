Jarmonica introduction

Jarmonica is the legacy migration flow, in which migrations are compiled Kotlin classes rather than scripts. The harmonica plugin described on the Harmonica introduction page is recommended for new projects.

How to use

1. Apply the plugin

Add the plugin to your build script:

plugins {
    id("jarmonica") version "3.0.0"
    kotlin("jvm") version "2.3.20"
}

Jarmonica relies on the Kotlin compiler to produce the migration classes, so it also needs a runtime classpath that carries the JDBC driver and the Harmonica library.

The plugin registers the tasks jarmonicaCreate, jarmonicaUp, jarmonicaDown, and jarmonicaVersion.

2. Set the migration package

Compiled migrations live in the package configured by the migrationPackage extra property or, failing that, derived from directoryPath:

extra["migrationPackage"] = "com.example.myapp.db"
extra["env"] = "Default"   // optional; defaults to "Default"

3. Configure the database connection

Configuration is a compiled DbConfig subclass or object named after the environment, in the migration package. For each environment you use, create a config/ file such as config/Default.kt:

import com.improve_future.harmonica.core.DbConfig
import com.improve_future.harmonica.core.Dbms

class Default : DbConfig() {
    init {
        dbms = Dbms.SQLite
        dbName = "example_app"
    }
}

4. Write a migration

Run ./gradlew jarmonicaCreate -PmigrationName=CreateUsers to scaffold one, or create the class manually. The class name must start with M and end with _, with the yyyyMMddHHmmssSSS timestamp in between — e.g. M<timestamp>_<Name> — because the timestamp is the migration version:

import com.improve_future.harmonica.core.AbstractMigration

class M20260830120000000_CreateUsers : AbstractMigration() {
    override fun up() {
        createTable("users") {
            varchar("name", size = 100, nullable = false)
        }
    }

    override fun down() {
        dropTable("users")
    }
}

5. Run the migrations

./gradlew jarmonicaCreate -PmigrationName=CreateUsers  # scaffold a migration
./gradlew jarmonicaUp -Pstep=2                         # apply up to two steps
./gradlew jarmonicaDown -Pstep=1                       # revert one step
./gradlew jarmonicaVersion                             # show the current version

Select a different environment with -Penv=test, matching the name of a DbConfig you have defined.
