Harmonica introduction

Harmonica migrates your database with Kotlin scripts (.kts). This page explains how to introduce Harmonica into your project.

Version 3.0.0 is the up-coming maintenance-restart release of this page's content. The legacy, compiled-class jarmonica plugin is covered separately.

Getting started

1. Apply the plugin

Add the plugin to your build script:

plugins {
    id("harmonica") version "3.0.0"
}

The plugin registers the tasks harmonicaUp, harmonicaDown, and harmonicaCreate.

2. Point the plugin at the migration directory

Set the directoryPath extra property to the directory that contains migration/ and config/ (the default is src/main/kotlin/db):

extra["directoryPath"] = "src/main/kotlin/com/example/myapp"

Add whatever the scripts need — the core library, your JDBC driver, and optionally the Exposed bridge — to the harmonica configuration:

dependencies {
    harmonica("com.improve_future:core:3.0.0")
    harmonica("org.xerial:sqlite-jdbc:3.45.3.0")
    //harmonica("com.improve_future:exposed:3.0.0")
}

3. Configure the database connection

Create config/<env>.kts for each environment. The environment is selected by the env extra property or the -Penv project property and defaults to default. The file evaluates to a DbConfig:

import com.improve_future.harmonica.core.DbConfig
import com.improve_future.harmonica.core.Dbms

DbConfig {
    dbms = Dbms.SQLite
    dbName = "example_app"
}

Available settings: dbms, host, port, dbName, user, password, and sslmode. Executed migration versions are tracked in the harmonica_migration table.

4. Write a migration

Run ./gradlew harmonicaCreate -PmigrationName=CreateUsers to scaffold a migration in migration/, or create one manually. Migration files are named <timestamp>_<Name>.kts and run in lexical order:

import com.improve_future.harmonica.core.AbstractMigration

object : AbstractMigration() {
    override fun up() {
        createTable("users") {
            varchar("name", size = 100, nullable = false)
            integer("age")
            boolean("active", default = true)
        }
        createIndex("users", "name")
        addTextColumn("users", "address")
    }

    override fun down() {
        dropTable("users")
    }
}

The full set of available methods is listed on the AbstractMigration API page and the migration method reference.

5. Run the migrations

./gradlew harmonicaUp      # apply all pending migrations
./gradlew harmonicaDown    # revert the latest migration

Select a different environment with -Penv=sqlite. Supported database systems are PostgreSQL, MySQL, SQLite, Oracle, and H2 (the SQL Server adapter is registered but not yet implemented).
