Welcome to Harmonica!

Harmonica is a database migration tool for the JVM written in Kotlin: a Gradle plugin backed by a JDBC core library, similar in spirit to Phinx and Rails migrations.

It provides migration in two ways:

  • Migrate with Kotlin scripts (.kts) — the recommended flow.
  • Migrate with compiled Kotlin classes — the legacy jarmonica flow.

See also the API documentation and the migration method reference.
